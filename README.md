# 北海道冬日之旅 2026 · Travel Journal 使用說明

純 HTML/CSS/JS 網站，**不需安裝、不需資料庫、不需任何程式環境**。

```
hokkaido-site/
├─ index.html        網站入口（不用改）
├─ css/style.css     外觀（顏色在最上面的 :root 區）
└─ js/
   ├─ data.js        ★ 行程、餐廳、住宿、天氣地點、清單預設值（要改內容就改這個）
   └─ 其他 .js       功能程式（不用改）
```

## 1. 在自己電腦預覽

- 最簡單：直接**雙擊 `index.html`**，用 Chrome / Safari / Edge 開啟即可。
- 少數瀏覽器（Safari）對本機檔案的照片儲存較嚴格，若相簿無法儲存，請用下一節的方法發佈後再使用。

## 2. 免費發佈成網址（三選一，Netlify 最簡單）

**A. Netlify Drop（不用註冊 Git，約 1 分鐘）**
1. 打開 https://app.netlify.com/drop ，註冊／登入免費帳號。
2. 把整個 `hokkaido-site` 資料夾拖進頁面。
3. 取得網址（如 `xxxx.netlify.app`），傳給男朋友即可。可在 Site settings 改成好記的名稱。

**B. GitHub Pages**
1. 在 github.com 建立免費帳號與新 repository（Public）。
2. 點 *Add file → Upload files*，把資料夾裡的**內容**（index.html、css、js）拖進去，Commit。
3. *Settings → Pages → Branch 選 main / root → Save*，約 1–2 分鐘後出現網址。

**C. Cloudflare Pages**：Workers & Pages → Create → Pages → Upload assets，拖入資料夾。

> 之後想改內容：改好 `data.js`，重新拖曳／上傳覆蓋即可。

## 3. 怎麼修改內容（用「記事本」或 VS Code 開 `js/data.js`）

規則只有一條：**只改引號 `"…"` 裡面的文字，不要刪逗號、引號、大括號。**

| 想改什麼 | 找哪裡 |
|---|---|
| 某個景點的時間、說明、地址 | 搜尋景點名稱，改 `time` / `desc` / `address` |
| Google Maps 搜尋字 | 該景點的 `map:"…"`（改成更精準的店名或地址） |
| 停留時間、營業時間、費用 | `stay` / `hours:{t:"…"}` / `price` |
| 移動時間 | 該景點的 `driveNext:{t:"…"}` |
| 新增一個景點 | 複製同一天 `items` 裡任一個 `{ … },` 整段，貼在想要的位置，改內容（`id` 要與別的不同） |
| 刪除景點 | 刪掉那一整段 `{ … },` |
| 住宿 | 檔案上方 `lodging` |
| 新增／修改餐廳 | `restaurants` 裡複製一整段 `{ … },` 修改。`days:[3]` 代表推薦給 DAY 3；`closedDow:[3]` 代表週三公休（0=週日…6=週六） |
| 想讓某餐廳出現在某餐 | 在該天的用餐項目 `meal:{rec:["餐廳id"]}` 加入餐廳的 `id` |
| 清單預設項目 | `checklist` |
| 天氣地點 | `weatherPlaces`（經緯度） |
| 預算分類 | `budgetCats` |
| 待確認事項 | `flags`；已解決就把整段刪掉 |

改壞了怎麼辦？重新整理頁面若變空白，代表 `data.js` 少了逗號或引號；還原剛才的修改即可。

## 4. 換成真實照片

網站內附的是**手繪風插畫佔位圖**（我無法從網路下載真實照片）。兩種方式換成真照片：

1. **最簡單（在網站上）**：每個景點／餐廳卡片的圖片右下角有「換成我的照片」，選圖即可。照片會存在**這台裝置的瀏覽器**裡（只有你自己看得到）。
2. **全站都看得到（寫進網站）**：把照片放進 `hokkaido-site/photos/` 資料夾（建議寬度 1600px 以內、檔名用英文），然後在 `data.js` 該景點加一行：
   `photo:"photos/biei-tree.jpg",`
   重新發佈後，你和男朋友打開都會看到。請只使用自己拍的或有授權的照片。

## 5. 預算與資料同步（重要）

- 預算、清單、相簿都存在**各自裝置的瀏覽器**，重新整理不會消失。
- **你和男朋友的手機不會自動同步。** 想合併：到「備份」頁，其中一人「匯出」→ 傳檔案 → 另一人「匯入」。含照片的備份檔會比較大。
- 清除瀏覽器資料、換手機、無痕模式都可能讓資料消失，出發前與旅途中請定期匯出備份。
- 匯率：預設值只是佔位，請在預算頁按「更新即時匯率」（需網路），或手動輸入你實際換匯的匯率。

## 6. 天氣

使用免費的 Open-Meteo API，提供現在天氣與**未來 16 天**預報。距離出發超過 16 天時，旅行日會顯示「預報尚未開放」。API 沒有「降雪機率」與官方警報，所以網站顯示降水機率與降雪量，並附上氣象廳警報、道路資訊等官方連結。

## 7. 常見問題

- **地圖空白／載入失敗**：內嵌地圖需要網路；仍可點「在地圖開啟」「導航前往」用 Google Maps 開啟。
- **字型跑掉**：字型來自 Google Fonts，離線時會改用系統字型，功能不受影響。
- **想改顏色**：`css/style.css` 最上方 `:root{ … }` 的色碼。
